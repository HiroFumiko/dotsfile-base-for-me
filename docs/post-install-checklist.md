# 導入後の手動確認

新Macで導入スクリプトが完了した後、本人が確認するための一覧です。
自動処理の完了はツールの導入・設定配置までを意味し、アプリが使用可能であることを保証しません。
確認結果はローカルで記入してください。初回設定の細かな操作手順は各アプリの案内に従います。

- [ ] 新しいターミナルを開き、シェルとプロンプトが表示される。
- [ ] 普段使うGUIアプリ（Ghostty、Cursorなど）を開ける。
- [ ] 普段使うCLI（Cursor Agent、agy、Claude Codeなど）を必要に応じて起動できる。
- [ ] Vimを開き、普段の編集操作ができる。
- [ ] 必要なアプリのログイン・利用許可・初回設定を、アプリの案内に従って済ませた。
- [ ] 必要に応じてXcode・SDK・シミュレーターなど、今回の自動導入範囲外のものを準備した。
- [ ] 新しいSSH鍵の発行・登録と、必要なローカル環境変数の設定を済ませた。
- [ ] 普段の作業を一つ行い、気になる点がないか確認した。

導入物の存在だけを機械的に確認したい場合は、リポジトリ内で`./scripts/check.sh`を実行できます。このチェックの成功も、実際の動作や認証状態を保証するものではありません。
